# Rotational-Earth-Three.JS 

Another cool beginner-friendly project where I added an Earth texture wrapper in the form of a .jpg file to a 3d spherical object; I was able to do this by following the 'Learn Three.js by Building 5 Projects' tutorial series, taught by Bobby Roe and hosted on freeCodeCamp's YouTube channel.

YouTube tutorial: https://www.youtube.com/watch?v=UMqNHi1GDAE

freeCodeCamp site: https://www.freecodecamp.org/

Bobby Roe github: https://github.com/bobbyroe/getting-started-with-threejs
